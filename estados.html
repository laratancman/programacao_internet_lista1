Estados e códigos HTTP

Os códigos de status HTTP são números enviados pelo servidor para informar se uma requisição foi concluída com sucesso ou se aconteceu algum problema.

Principais categorias

  • 1xx – Informações.
  • 2xx – Sucesso.
  • 3xx – Redirecionamento.
  • 4xx – Erros relacionados à requisição do cliente.
  • 5xx – Erros relacionados ao servidor.

Exemplos de códigos

Código Significado Explicação
200 OK Requisição realizada com sucesso.
301 Moved Permanently O endereço foi alterado permanentemente.
302 Found Redirecionamento temporário.
400 Bad Request Requisição inválida.
403 Forbidden Acesso proibido.
404 Not Found Recurso não encontrado.
500 Internal Server Error Erro interno do servidor.
