Atividade 4 — Especificidade de seletores CSS

As regras definem a cor dos itens de uma lista. Quando mais de uma regra pode ser aplicada ao mesmo elemento, o navegador considera a especificidade do seletor: seletores com ID têm maior peso que seletores de classe e atributos, que por sua vez têm maior peso que seletores de elemento.

Explicação de cada regra

Regra 1 — li { color: red; }

Seleciona todos os elementos <li> da lista e define a cor vermelha. É uma regra geral, pois seleciona apenas pelo nome da tag. Ela aparece no item Abacaxi, que não recebe nenhuma regra mais específica.

Regra 2 — .churras { color: green; }

Seleciona todos os elementos que possuem a classe churras. A intenção é deixar os itens dessa categoria verdes. Porém, nos itens em que outra regra mais específica também se aplica, a cor verde é substituída.

Regra 3 — .fruta { color: gray; }

Seleciona todos os elementos que possuem a classe fruta e define a cor cinza. É aplicada aos itens de frutas, exceto quando uma regra com maior especificidade determina outra cor.

Regra 4 — li + li.churras { color: black; }

O seletor + representa o irmão adjacente. Portanto, seleciona um elemento li com a classe churras que aparece imediatamente depois de outro li. Como os itens da lista estão um após o outro, essa regra seleciona Carne, Linguiça e Pão de alho. Ela é mais específica que a regra 2, por isso esses itens deixam de ser verdes e passam a ser pretos — exceto o último, que também é atingido pela regra 5.

Regra 5 — .churras[draggable="true"] { color: magenta; }

Seleciona elementos que possuem simultaneamente a classe churras e o atributo draggable com o valor true. No HTML apresentado, isso corresponde ao item Pão de alho. Essa regra prevalece sobre a regra 4 porque combina uma classe e um atributo, tendo maior especificidade que o seletor da regra 4.

Regra 6 — #lip1, #lip2, #lip3 { color: blue; }

A vírgula separa seletores: a regra selecionaria elementos com os IDs lip1, lip2 ou lip3. No HTML da figura, não há elemento com ID lip1; os itens com IDs lip2 e lip3 são Pera e Uva. A cor azul prevalece sobre a regra da classe .fruta, pois um seletor por ID tem maior especificidade.

Regra 7 — #lip3.fruta { color: orange; }

Seleciona um elemento que tenha, ao mesmo tempo, o ID lip3 e a classe fruta. O elemento correspondente é Uva. Como esse seletor é mais específico que o seletor de ID usado na regra 6 (ele também exige uma classe), a cor final de Uva é laranja, e não azul.

Regra 8 — ol > li.churras#lip5 { color: purple; }

Seleciona um elemento li com a classe churras e o ID lip5, desde que seja filho direto de um ol. Apesar de ser um seletor bastante específico, nenhum item recebe essa regra, porque no HTML apresentado não existe um elemento com ID lip5. O último item tem ID lip7, não lip5. Por isso, a regra não altera a cor de nenhum elemento.

Conclusão

As cores finais não dependem apenas da ordem em que as regras aparecem no CSS. Quando várias regras atingem o mesmo elemento, a especificidade é considerada: IDs têm mais peso que classes e atributos, e estes têm mais peso que seletores de elementos. Seletor que não encontra um elemento correspondente, como a regra 8, não produz alteração.
