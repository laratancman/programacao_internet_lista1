O que é uma regra CSS?

Uma regra CSS é um conjunto de instruções utilizado para definir a aparência dos elementos de uma página HTML.

Ela é formada por um seletor, uma propriedade e um valor.

Exemplo prático

No exemplo acima, o seletor é p, a propriedade é color e o valor é blue.

Isso significa que todos os parágrafos terão a cor azul e o tamanho da fonte será de 20 pixels.
